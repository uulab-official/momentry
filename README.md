# Momentry

Momentry is a UULab Expo application for private diary, movie, and book memories.

- Active application: [`apps/app`](apps/app)
- Package/bundle ID: `kr.co.uulab.momentry`
- Expo SDK/runtime: SDK 57 / runtime `1.0.0`

Start here:

```bash
cd apps/app
npm install
npm run verify
npm run ios
```

See [`apps/app/README.md`](apps/app/README.md) for architecture, app routes, OTA/build commands, release blockers, and local data migration notes.
