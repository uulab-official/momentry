### 2026-07-30 네이티브 레이아웃 회귀 수정

- iPhone 16 계열 430×932 시뮬레이터에서 홈·전체 화면을 직접 확인하고, 368×800 및 320×568 Web에서 홈·전체·설정의 가로 행을 재검증

- 하단 탭을 `64pt + bottomInset`으로 계산하며 label/icon/item 높이를 고정해 홈 인디케이터 영역과 분리
- 카드·설정 행은 `width: 100%`, `minWidth`, `flexShrink` 규칙을 명시해 좁은 화면에서도 가로 구조 유지
- 탭 navigator가 이미 하단 안전 영역을 예약하므로 목록 FAB에서 safe-area를 다시 더하던 이중 패딩 제거
- SDK 패치 정렬은 UI 수정과 무관하게 검증 중 `expo install --fix`로 일시 발생했으며, package/lockfile을 현재 스토어 바이너리 기준선으로 복원
- `npm run ota:check` 통과: TypeScript·ESLint·OTA용 Expo Doctor 19/19, 공개 Expo config, native baseline guard 확인
- 앱바·탭·가로 행·FAB 수정은 JS/TS·스타일 변경만 포함하므로 runtime `1.0.0`의 OTA 대상이며 새 바이너리는 필요하지 않음
